Excepciones del vendedor

Como entrar

Sección titulada «Como entrar»

En la pantalla principal aparece un boton de alerta cuando hay excepciones pendientes. Tambien se puede entrar desde la accion Excepciones en esa misma vista.

Que podes hacer

Sección titulada «Que podes hacer»
  1. Aprobar una excepcion puntual.
  2. Denegar una excepcion puntual.
  3. Aprobar todas.
  4. Denegar todas.

Cada accion pide confirmacion antes de enviarse.

Datos que muestra cada excepcion

Sección titulada «Datos que muestra cada excepcion»
  1. Cupon involucrado.
  2. Persona solicitante (anonimizada en la vista).
  3. Fecha.
  4. Edad solicitada para excepcion.

Buenas practicas

Sección titulada «Buenas practicas»
  1. Evita aprobar en bloque si no revisaste cada caso.
  2. Usa accion masiva solo cuando el criterio sea realmente comun para todo el lote.
  3. Si hay dudas de politica comercial, consulta primero al encargado responsable.
